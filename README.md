# The Addis Field Guide Map

Created by Carlos Opitz.

A map of places in Addis Ababa compiled from What's Out Addis and the CLO's Staff Picks. The page reads its places and its texts from the Google Sheet "The Addis Field Guide", so all edits happen in the sheet:

- **Places tab:** add, change or remove places.
- **Map settings tab:** title, subtitle, credit line, footer note, button texts, the suggestion form link, and the names shown for sources and categories.
- **Icon key tab:** the emoji for each type of place.

The map reads the sheet's published **Public** and **Map settings** tabs (File > Share > Publish to web). Changes show up within about five minutes.

## Files

| File | What it is |
| --- | --- |
| `index.html` | The map page |
| `config.js` | The link to the published sheet (the only file you may need to edit) |
| `base-major.json`, `base-minor.json` | Street map data from OpenStreetMap |
| `robots.txt` | Asks search engines not to list the site |
